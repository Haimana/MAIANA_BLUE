# MAIANA BLUE

Firmware and hardware materials for the MAIANA-class AIS transponder ecosystem. The design builds on the open [MAIANA project](https://github.com/peterantypas/maiana) (GPL v3, Peter Antypas).

## In this repository

- **Firmware/** — AIS firmware (STM32CubeIDE tree and a **VS Code / PlatformIO** sibling), plus the N2K variant. Start with [Firmware/README.md](Firmware/README.md) for layout and build pointers.
- **CAD/** — STEP models (enclosures, antennas).
- **Manuals/** — Assembly and related documentation.
- **Schematics/** — Hardware reference drawings.
