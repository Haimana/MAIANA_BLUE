# Firmware layout

- **`Maiana_Blue_AIS_Firmware_VSCode_PlatformIO`** — AIS transponder firmware built with **VS Code + PlatformIO** (`platformio.ini`). Use this tree for `pio run` / multi-environment builds. Build artifacts (`.pio/`) are ignored by git. The original STM32CubeIDE / Eclipse project it was ported from has been removed (available in git history).

- **`Maiana_Blue_N2K_Firmware`** — N2K variant (unchanged).
